# 함께 작업하기

매뉴얼은 만든 사람이 소유자가 됩니다. 소유자는 다른 사람을 편집자로 초대할 수 있습니다.

## 편집자 초대

**매뉴얼 설정 → 편집자**에서 이메일 주소를 넣고 초대합니다. 초대받은 사람이 그 이메일로 Google 로그인하면 문서를 편집할 수 있습니다.

초대받는 사람이 booker에 가입한 적이 없어도 됩니다. 먼저 초대해 두면, 나중에 로그인하는 순간부터 권한이 생깁니다.

## 권한 차이

| 할 수 있는 일 | 소유자 | 편집자 |
| --- | --- | --- |
| 문서 작성·수정·삭제 | O | O |
| 발행·발행 취소 | O | O |
| 문서 순서 변경 | O | O |
| 이미지 업로드 | O | O |
| 피드백 확인 | O | O |
| 매뉴얼 이름·주소·공개 범위 변경 | O | X |
| 편집자 추가·제거 | O | X |
| 매뉴얼 삭제 | O | X |

## 공개 범위

- **공개** — 누구나 읽을 수 있습니다. 검색엔진에도 노출됩니다.
- **비공개** — 소유자와 편집자만 볼 수 있습니다.

비공개로 두었다가 준비가 끝난 뒤 공개로 바꾸는 방식도 좋습니다.
