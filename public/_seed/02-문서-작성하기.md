# 문서 작성하기

문서는 마크다운으로 씁니다. 문법을 외울 필요는 없습니다. 툴바 버튼과 단축키로 넣을 수 있고, 오른쪽에 결과가 바로 보입니다.

## 편집기 화면

| 버튼 | 설명 |
| --- | --- |
| 편집 · 분할 · 미리보기 | 화면 배치를 바꿉니다. 좁은 화면에서는 분할이 숨습니다. |
| 발행 | 지금 초안을 공개합니다. |
| ⋯ | 발행 이력, 주소 변경, 발행 취소, 삭제 |

## 단축키

| 기능 | macOS | Windows |
| --- | --- | --- |
| 저장 | `⌘S` | `Ctrl+S` |
| 굵게 | `⌘B` | `Ctrl+B` |
| 기울임 | `⌘I` | `Ctrl+I` |
| 링크 | `⌘K` | `Ctrl+K` |
| 미리보기 전환 | `⌘Enter` | `Ctrl+Enter` |

목록에서 Enter를 누르면 다음 항목이 자동으로 이어집니다. 빈 항목에서 Enter를 한 번 더 누르면 목록이 끝납니다. Tab과 Shift+Tab으로 들여쓰기를 조절합니다.

## 자주 쓰는 문법

### 제목

제목은 `#`의 개수로 단계가 정해집니다. 본문에서는 `##`와 `###`만 오른쪽 목차에 표시되니, 문서 구조는 이 두 단계로 잡는 편이 읽기 좋습니다.

### 목록과 체크리스트

- 글머리 목록은 `-`로 시작합니다
- 하위 항목은 공백 두 칸을 넣습니다
  - 이렇게 들어갑니다

체크리스트는 `- [ ]`와 `- [x]`로 씁니다.

- [x] 완료한 항목
- [ ] 남은 항목

### 표

```
| 항목 | 값 |
| --- | --- |
| 이름 | booker |
```

표가 화면보다 넓으면 표 안에서만 가로로 스크롤됩니다. 문서 전체가 밀리지는 않습니다.

### 코드

문장 안에서는 `` `백틱` ``으로 감싸고, 여러 줄은 백틱 세 개로 감쌉니다. 언어 이름을 적으면 색이 입혀집니다.

```python
def greet(name: str) -> str:
    return f"안녕하세요, {name}님"
```

### 안내 상자

`>`로 시작하면 안내 상자가 됩니다. 놓치면 곤란한 내용에만 쓰세요. 너무 자주 쓰면 아무도 읽지 않습니다.

## 이미지

이미지는 **붙여넣거나 끌어다 놓으면** 바로 올라갑니다. 파일 선택 버튼도 있습니다. 한 장에 10MB까지, PNG·JPEG·GIF·WebP·AVIF·SVG를 지원합니다.

올라간 이미지는 매뉴얼을 편집할 수 있는 사람만 올릴 수 있고, 읽기는 누구나 됩니다.

## 문서 계층

편집 화면의 **위치**에서 상위 문서를 지정하면 왼쪽 목차에서 하위로 들어갑니다. 순서를 크게 바꾸려면 **매뉴얼 설정 → 문서 순서**에서 끌어다 옮기는 편이 편합니다.
