# 찾기와 내보내기

## 문서 검색

왼쪽 목차 위의 검색창은 **지금 보고 있는 매뉴얼 안에서** 제목과 본문을 찾습니다. 결과에는 찾은 문구의 주변 문장이 함께 표시됩니다.

홈 화면의 검색창은 **공개된 모든 매뉴얼**을 대상으로 합니다. 이 검색은 사이트를 배포할 때 만들어 둔 색인을 씁니다. 따라서 방금 발행한 문서는 다음 배포 이후에 검색에 나타납니다.

## 인쇄와 PDF

왼쪽 아래 **인쇄 · PDF로 저장**을 누르면 매뉴얼 전체가 목차와 함께 한 문서로 펼쳐지고 인쇄 창이 열립니다. 대상에서 **PDF로 저장**을 고르면 파일로 받을 수 있습니다.

인쇄본에서는 화면용 요소가 빠지고, 링크는 주소가 괄호로 함께 인쇄됩니다. 코드 블록과 표는 페이지 중간에서 잘리지 않게 처리됩니다.

## 링크 공유

각 매뉴얼은 고유한 주소를 가집니다.

```
https://booker.sanghak.kr/s/매뉴얼주소/문서주소
```

왼쪽 아래 **링크 복사**로 매뉴얼 주소를 바로 복사할 수 있습니다.

> **주의**
>
> 매뉴얼 주소를 바꾸면 기존 링크는 열리지 않습니다. 이미 공유한 문서라면 바꾸기 전에 한 번 더 생각하세요.
