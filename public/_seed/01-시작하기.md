# 시작하기

booker는 마크다운으로 매뉴얼을 쓰고 웹에 공개하는 도구입니다. 문서를 쓰면 목차와 검색이 있는 사이트가 되고, 읽는 사람은 로그인할 필요가 없습니다.

이 설명서는 booker로 만들었습니다. 왼쪽 목차와 오른쪽 페이지 내 목차, 아래의 피드백 버튼이 모두 기본 기능입니다.

## 무엇에 쓰면 좋은가

- **제품 사용 설명서** — 설치, 사용법, 자주 묻는 질문
- **사내 업무 매뉴얼** — 절차, 담당자, 문제 해결
- **API 문서** — 엔드포인트와 오류 코드

문서 수가 수십 개 규모이고, 한두 사람이 관리하며, 외부에 공개하거나 링크로 공유하는 용도에 맞게 만들었습니다.

## 5분 안에 시작하기

1. 오른쪽 위 **Google로 로그인**을 누릅니다.
2. **새 매뉴얼**에서 이름을 적습니다. 이름만 넣으면 나머지는 나중에 바꿀 수 있습니다.
3. 시작 구성을 고릅니다. 빈 문서보다 템플릿으로 시작하는 편이 훨씬 빠릅니다.
4. 왼쪽 목차에서 문서를 골라 **편집**을 누르고 내용을 채웁니다.
5. **발행**을 누르면 공개됩니다.

> **참고**
>
> 저장과 발행은 다릅니다. 저장은 초안에만 반영되고, 공개 사이트에 올라가는 것은 발행한 시점의 내용입니다. 자세한 내용은 [초안과 발행](/s/guide/초안과-발행)을 보세요.

## 화면 구성

| 영역 | 내용 |
| --- | --- |
| 왼쪽 | 문서 목록, 검색, 인쇄, 설정 |
| 가운데 | 본문 |
| 오른쪽 | 이 페이지의 목차 |

화면이 좁으면 왼쪽 목차는 상단의 메뉴 버튼 안으로 들어갑니다.
